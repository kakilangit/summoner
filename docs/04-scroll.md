# Scroll (File Browser)

Each realm has a dedicated data directory at `~/.summoner/workspaces/<realm_id>`. The **Scroll** page provides a file browser for navigating, viewing, and downloading files in this directory.

## Features

- Browse the workspace directory tree
- Navigate into subdirectories
- Download individual files
- Download directories as zip archives
- Open the workspace directory in the OS file manager (local mode only)

## Workspace Directory

The workspace directory is created automatically when a realm is created. It serves as the working directory for agents that interact with the filesystem via MCP tools.

Files generated by agents (code, reports, exports) are stored here and accessible through the Scroll interface.

## Routes

| Path | Description |
|------|-------------|
| `/realms/:workspace_id/scrolls` | Root of workspace file browser |
| `/realms/:workspace_id/scrolls/*path` | Navigate to a specific path |

## File Downloads

- **Single file**: Click a file to download it directly
- **Archive**: Download an entire directory as a `.zip` file

## Local Mode

When running locally (`Summoner.Features.local_mode?` is true), an "Open in file manager" button appears, opening the workspace directory in Finder (macOS), Nautilus (Linux), or Explorer (Windows).
